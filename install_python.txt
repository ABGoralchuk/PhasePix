================================================================================
  PhasePix: Повна інструкція та команди для встановлення на Windows
================================================================================

Цей файл містить усі необхідні команди для запуску у терміналі Windows
(PowerShell або Командний рядок CMD). Ви можете копіювати та запускати їх по черзі.


================================================================================
КРОК 0. СИСТЕМНІ СИСТЕМНІ КОМПОНЕНТИ WINDOWS (КРИТИЧНО ВАЖЛИВО)
================================================================================
Для роботи бібліотек комп'ютерного зору та нейромереж (PyTorch, OpenCV, SciPy)
на Windows обов'язково потрібен пакет Microsoft Visual C++ Redistributable.

Виконайте команду для його автоматичного встановлення:

winget install Microsoft.VCRedist.2015+.x64

(Якщо він уже був встановлений — система просто повідомить про це).


================================================================================
КРОК 1. ВСТАНОВЛЕННЯ PYTHON 3.11 (якщо ще не встановлено)
================================================================================
Python 3.11 є найбільш стабільною та перевіреною версією для роботи з Cellpose та PyTorch.

Виконайте команду:

winget install -e --id Python.Python.3.11

Примітки:
- Якщо winget запитає підтвердження ліцензії, натисніть 'Y' (Yes).
- Після завершення встановлення ОБОВ'ЯЗКОВО ПЕРЕЗАПУСТІТЬ термінал, щоб Windows підхопила шляхи (PATH).
- Перевірте успішність встановлення командою:
  python --version


================================================================================
КРОК 2. СТВОРЕННЯ ТА АКТИВАЦІЯ ВІРТУАЛЬНОГО СЕРЕДОВИЩА (.venv)
================================================================================

1. Перейдіть у папку проєкту PhasePix (замініть шлях на ваш реальний):
cd /d "C:\Users\YourUsername\Desktop\PhasePix"

2. Створіть чисте віртуальне середовище:
python -m venv .venv

3. Активуйте віртуальне середовище:
# Якщо ви використовуєте стандартний CMD (Командний рядок):
.venv\Scripts\activate.bat

# АБО якщо ви використовуєте PowerShell:
.venv\Scripts\Activate.ps1

*(Якщо у PowerShell з'явиться помилка обмеження скриптів ExecutionPolicy,
 один раз виконайте:
 Set-ExecutionPolicy Unrestricted -Scope CurrentUser
 після чого повторіть активацію).*

4. Оновіть pip та інструменти збирання:
python -m pip install --upgrade pip setuptools wheel


================================================================================
КРОК 3. ВСТАНОВЛЕННЯ БІБЛІОТЕК (PYTORCH, CELLPOSE ТА ЗАЛЕЖНОСТЕЙ)
================================================================================

Оберіть один із варіантів залежно від конфігурації вашого комп'ютера:

--------------------------------------------------------------------------------
ВАРІАНТ А (Рекомендовано для комп'ютерів із відеокартами NVIDIA GeForce / RTX):
Встановлює PyTorch з апаратним прискоренням CUDA (12.1) для швидкої сегментації:
--------------------------------------------------------------------------------

pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
pip install -r requirements.txt


--------------------------------------------------------------------------------
ВАРІАНТ Б (Для звичайних ноутбуків / ПК без відеокарти NVIDIA — розрахунки на CPU):
--------------------------------------------------------------------------------

pip install torch torchvision
pip install -r requirements.txt


--------------------------------------------------------------------------------
РЕЗЕРВНИЙ ВАРІАНТ (якщо виникають конфлікти фіксованих версій із requirements.txt):
Встановлює найактуальніші сумісні версії всіх основних модулів безпосередньо:
--------------------------------------------------------------------------------

pip install streamlit streamlit-drawable-canvas cellpose opencv-python-headless pandas numpy scipy scikit-image matplotlib seaborn tifffile roifile fill_voids fastremap


================================================================================
КРОК 4. ПЕРЕВІРКА ВСІХ КОМПОНЕНТІВ ТА ПРИСКОРЕННЯ
================================================================================
Виконайте коротку діагностичну команду в терміналі:

python -c "import streamlit, cellpose, cv2, torch; print('=== УСПІХ! PhasePix готовий до роботи ==='); print('Device:', 'NVIDIA CUDA (' + torch.cuda.get_device_name(0) + ')' if torch.cuda.is_available() else 'CPU (Процесор)')"


================================================================================
КРОК 5. ЗАПУСК ПРОГРАМИ
================================================================================
Тепер для запуску достатньо:

1. Двічі клікнути на готовий файл запуску у папці проєкту:
   phasepix.bat

2. Або запустити вручну з активованого терміналу:
   streamlit run app.py
